# ADR-0005: 재사용 액션은 관리자 반입 전용으로 한다

- **상태**: 채택됨
- **일자**: 2026-08-07
- **해소한 질문**: Q-01 — 프로젝트에서 가장 오래 열려 있던 최우선 위험
- **관련**: [ADR-0002](0002-github-compatibility.md), [ADR-0003](0003-ci-isolation-container-runtime.md),
  CON-01, CON-05, ASM-10, NFR-COMPAT-05, NFR-OPS-08

## 맥락

워크플로 파일은 남이 만든 재사용 부품을 참조한다. 한 파일에 보통 5~20개가 들어가고,
상류에서는 실행 시점에 그것을 인터넷에서 내려받는다.

우리 제품은 폐쇄망에서 돌아간다(CON-01). 부품 하나만 못 가져와도 워크플로 전체가
멈추므로, **문법을 똑같이 읽어들여도 실제로는 아무것도 동작하지 않는다.**
이것이 헌장의 최우선 위험이었다.

### 확인한 사실

상류 문서에서 확인한 액션 유형은 셋이다 — 컨테이너 기반, JavaScript 기반, 복합.
컨테이너 기반은 리눅스 러너에서만 실행된다. JavaScript 기반은 Node.js 런타임을
요구하며 순수 JavaScript여야 한다.

## 결정

**액션은 관리자가 반입한 것만 사용한다. 우리는 액션을 구현해 내장하지 않는다.**

- 인스턴스는 워크플로의 액션 참조를 **내부 사본으로 해석**한다.
  런타임에 외부로 나가지 않는 것이 기본값이며, 이는 설정으로도 뒤집을 수 없다.
- 저장·반입 형식은 **컨테이너 이미지로 통일**한다. ADR-0003이 컨테이너 런타임을
  필수로 정했으므로 반입 절차가 이미지 하나의 문제로 수렴한다(NFR-OPS-08).
- 반입 대상을 찾고 가져오고 등록하는 일을 관리자 혼자 감당하게 두지 않는다.
  **도구와 문서가 이 결정의 일부다**(아래 파생 요구).

## 정직하게 감수하는 것

**설치 직후에는 어떤 워크플로도 돌지 않는다.** 이것이 이 선택의 대가다.
내장 부품이 없으므로 관리자가 반입을 마치기 전까지 CI는 비어 있다.

이 격차를 도구로 메운다. 관리자가 「무엇이 필요한지」를 손으로 알아내야 한다면
이 결정은 현장에서 실패한다.

## 파생 요구

| 요구사항 | 내용 |
| --- | --- |
| `FR-CI-05` | 액션 참조를 내부 사본으로 해석. `보류` 해제 |
| `FR-CI-20` | 저장소의 워크플로를 훑어 **필요한 액션 목록을 산출**한다. 반입 전 무엇이 없는지 알려준다 |
| `FR-CI-21` | 반입 도구 — 연결된 환경에서 액션을 이미지로 만들어 내보내고, 폐쇄망에서 들여와 등록한다 |
| `FR-CI-22` | 반입 목록의 버전 관리와 갱신. 상류가 바뀌었을 때 관리자가 알 수 있어야 한다 |
| `NFR-SUPPORT-05` | 폐쇄망 반입 가이드 문서. 절차가 문서와 도구 양쪽에 있어야 한다 |

## 아키텍처 정책

우리가 배포하는 것 — 러너, 기본 이미지, 반입 도구 — 은 보장 등급 두 아키텍처를
모두 제공한다.

**관리자가 반입한 상류 액션의 아키텍처는 관리자 책임이다.** 상류 이미지가 arm64를
제공하지 않으면 arm64 인스턴스에서 그 액션은 동작하지 않는다. 우리가 없앨 수 없는
제약이므로 감추지 않고 문서와 진단에 드러낸다. FR-CI-20이 반입 시점에 이를 경고한다.

## ASM-10의 성격이 바뀐다

기존 가정은 「재사용 액션의 라이선스가 **인스턴스 내부 재배포**를 허용한다」였다.
우리가 액션을 배포하지 않기로 했으므로 **우리의 재배포 위험은 사라진다.**

가정은 「조직이 자기 인스턴스에 내부 사용 목적으로 반입하는 것이 라이선스상
허용된다」로 좁아진다. 훨씬 안전한 명제이지만 여전히 미검증이며,
반입 도구가 라이선스 정보를 함께 가져와 관리자에게 보여주는 것으로 대응한다.

## 결과

**긍정** — 재배포 라이선스 위험이 우리에게서 사라진다. 구현량이 가장 적다.
호환 범위가 좁아지지 않는다 — 관리자가 무엇이든 반입할 수 있다.
CON-01을 설정으로도 뒤집을 수 없게 지킨다.

**부정 / 감수하는 것** — 설치 직후 CI가 비어 있다. 관리자 운영 부담이 늘어
NFR-OPS-11(겸직 관리자 1명)을 압박한다. 상류 갱신 추종이 관리자 몫이 된다.
